# 대구대학교 소개 페이지

대구대학교를 소개하는 비공식 단일 페이지 웹사이트입니다. (학습용)

## 구성
- **건학정신** — 사랑 · 빛 · 자유
- **역사** — 장애인 교육기관에서 종합대학교까지
- **특성화** — 특수교육 · 재활과학, 배리어프리 캠퍼스
- **학문 분야** — 단과대학 카드를 누르면 벤토 그리드로 전공 목록이 펼쳐지고, 전공을 누르면 학과 홈페이지로 이동
- **캠퍼스** — 경산캠퍼스 · 대명캠퍼스

## 실행
별도 설치 없이 `index.html`을 브라우저로 열면 됩니다.

## 참고
- 학과 정보는 2026학년도 [대구대학교 홈페이지](https://www.daegu.ac.kr) 기준입니다.
- 배리어프리 관련 내용은 2020년 장애대학생 교육복지지원 실태평가 보도(2021년 2월) 기준입니다.
- 정확한 최신 정보는 대구대학교 공식 홈페이지를 참고하세요.
